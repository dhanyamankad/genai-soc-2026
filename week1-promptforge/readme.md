## 🔧 Week 1 — PromptForge Multi-Mode AI Assistant

A Gradio web app with 4 selectable AI personas, each with a unique system prompt, few-shot examples, and output style.

👉 [View Project](./week1-promptforge)

### 🎭 Personas
- **Technical Explainer** — explains complex topics clearly using analogies
- **Debate Coach** — argues both sides of any topic fairly
- **Code Reviewer** — reviews code and returns structured JSON output
- **Creative Writer** — responds in vivid, cinematic narrative prose

### 🧠 Concepts Used
- System Prompts & Few-Shot Examples
- Groq API with Streaming
- Gradio Blocks UI
- JSON Parsing & Markdown Rendering
- Environment Variables & API Key Security
